# RevitTask



1. Напрямок визначається по кривій першого елемента, нормалізується різниця між кінцем і початком. Далі ми ним оперуємо щоб йти вздовж цього напрямку.(GetPathDirection)
2. Робоча зона визначається з урахуванням мінімального відступу від країв (minEdgeOffsetInFeet), загальної довжини кондуітів та кроку (stepInFeet). Точки генеруються циклом за допомогою вектора напрямку і крока
3. Спочатку обчислюється кут нахилу далі повертається з-за допомогою ElementTransformUtils.RotateElement (RotatePerpendicular)
